# Placement Cell Management System

A web-based Training and Placement Cell Management System developed using PHP, MySQL, HTML, CSS, and JavaScript.

## Features

- Add, edit and delete placement drives
- Manage eligible branches, CGPA and backlog criteria
- Student application system
- Resume upload
- View student applications
- Update application status
- Auto Shortlist feature
- MySQL database integration

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Project Purpose

This system helps the Training and Placement Cell manage placement drives and student applications efficiently through a centralized web application.
